# Versioning and source hierarchy

Prefer exact-release official docs and source; use current main docs only with a checked date. Use primary papers for original algorithms. Treat RFCs as proposals until merged and released. Record vLLM, Python, PyTorch, CUDA / ROCm, driver, GPU, model revision, flags and date checked. A moving main URL is discovery, not an immutable code citation. Check installed commands with `vllm --version` and `vllm serve --help`.
